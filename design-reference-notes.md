# Frontend redesign reference notes

## MetalForge

Observed patterns from [metalforge.xyz](https://metalforge.xyz/): a near-black canvas, extremely high-contrast typography, a compact utility navigation, a centered statement-led hero, one primary action, an interactive visual effects gallery, small status/pill labels, and a premium “playground” feel built around motion and live previews. The useful translation for mashk-09 is not shader imitation; it is the idea of turning the dashboard into a live instrument with a strong hero statement, one clear run control, subtle material gradients, and a tactile evidence gallery.

## Awwwards dark-mode collection

Observed patterns from [Awwwards’ dark-mode collection](https://www.awwwards.com/awwwards/collections/dark-mode/): editorial-scale headings, generous negative space, dark/light contrast used as a deliberate interaction, mouse-driven or transition-led moments, and compositional layouts that feel like curated experiences rather than dense admin screens. The redesign should borrow the hierarchy, pacing, transition cues, and intentional typography while keeping mashk-09’s operations context and data legibility.

## Direction for mashk-09

Reframe the existing dashboard as a “sealed-world instrument” with a dramatic command header, a luminous synthetic-world visualizer, a split red/blue control rail, evidence cards that expand on interaction, a clearer generation scrubber, and a softer grid/panel system. Keep all API endpoints and persistence intact. Add only client-side presentation and interaction changes; do not add external assets or external network calls.
